# Python Lab

Hands-on Python exercises, organized by lab.

## Lab 1 — Python Basics

| File | Topic |
| --- | --- |
| `lab1/variable_practice.py` | Variables and `type()` |
| `lab1/greeting.py` | User input and f-strings |
| `lab1/arithmetic.py` | Basic arithmetic and zero-division handling |
| `lab1/celsius_to_fahrenheit.py` | Temperature conversion |
| `lab1/string_manipulation.py` | String methods and slicing |
| `lab1/escape_sequence.py` | Tabs and newlines |
| `lab1/calculator.py` | Optional menu-driven calculator |

## Run an exercise

Run commands from the project root:

```powershell
python lab1/variable_practice.py
python lab1/greeting.py
```

Interactive programs prompt for their required input.
