# Concept Check

1. **Why is a `while` loop useful in the ATM program?**  
   The menu must keep running until the user chooses to exit, so the number of iterations is not known in advance.

2. **Why does the reverse guessing game use binary search?**  
   Each response eliminates half of the possible range, making the game efficient.

3. **Why is input validation important for marks?**  
   It prevents non-numeric values and marks outside 0 to 100 from affecting the average.

4. **What does `% 5 == 0` check?**  
   It checks whether a number is divisible by 5.
