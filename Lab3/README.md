# Lab 3 - Star Pattern and Matrix Operations

## Programs

### 1. Star Pattern

`star_pattern.py` takes a positive integer `n` and prints a right-angled star pattern using nested loops. The pattern is created dynamically for any positive value of `n`.

### 2. Matrix Operations

`matrix_operations.py` accepts a 3 × 3 matrix and uses Python lists and loops to:

1. Display the matrix in rows and columns.
2. Find the sum of all elements.
3. Find the sum of the main diagonal.
4. Find the largest and smallest elements.
5. Display the transpose.

NumPy is not used.
